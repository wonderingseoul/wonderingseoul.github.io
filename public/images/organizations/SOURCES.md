# Organization assets

These marks identify past or current education and employment entries.

- KAIST: official website wordmark, https://www.kaist.ac.kr/site/kr/img/layout/logo.svg ; UI guidance https://www.kaist.ac.kr/en/html/kaist/011901.html
- Sungkyunkwan University: official English signature, https://www.skku.edu/_res/skku/img/sub/symbol2_img35.png ; UI guidance https://www.skku.edu/eng/symbol_04.do
- U.S. Embassy: general U.S. embassy seal (not a Seoul-specific mark), U.S. Government / Offnfopt, public-domain file: https://commons.wikimedia.org/wiki/File:Seal_of_an_Embassy_of_the_United_States_of_America.svg ; 250px PNG rendition retrieved from Wikimedia Commons. The Embassy's own website blocked retrieval.

Image proportions and original colors are preserved. The SKKU symbol is isolated from the official signature with a CSS viewport; the original file is unchanged. Project/paper images outside this folder were supplied by the portfolio owner.

- us-army.png: U.S. Army logo supplied by the user, 2026-09-28.
